# Source

Material under `assets/` is adapted from
[teaching-skills](https://github.com/yujxzjcn/teaching-skills) — a teaching
lifecycle suite for university professors (MIT License, see
`LICENSE-teaching-skills` in this directory).

Templates and deep-dive references are kept close to verbatim; the prose
workflows that consumed them were rewritten into this skill's own reference
docs (`../plan.md`, `../study.md`, `../quiz.md`, `../review.md`,
`../mentor.md`, `../deliver.md`, `../pedagogy.md`, `../state.md`).

Layout: `<area>/templates/` and `<area>/references/` keep the upstream
per-area structure; `scripts/` holds the course-facing Python checkers and
exporters; `shared/` holds the machine-checkable Course Passport schema.
Upstream `agents/`, `examples/`, tests, and dev tooling were dropped.
