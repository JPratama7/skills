# Reframe Techniques

Load when the user is stuck in one frame and won't engage with alternatives — they keep returning to the same approach, dismissing others without reasoning, or treating one assumption as untouchable.

## Spot the frame

A "frame" is the set of assumptions the user treats as fixed. Common signs they're locked in:

- Every alternative you propose gets re-interpreted through their existing approach ("yes but how would that work with [their thing]?").
- They dismiss options with feelings ("that feels wrong") not reasons.
- They keep refining the same idea instead of considering others.
- The conversation has narrowed to implementation details of one approach.

## Reframe moves

Don't argue against their frame — that entrenches it. Instead, shift the vantage point:

### Steelman-then-step-outside
Argue their chosen approach *better than they have*, then ask: "if this is the strongest case for X, what would have to be true for X to still be the wrong call?" This makes the frame visible without attacking it.

### Change the comparison set
If they're comparing approaches against each other, change the reference: "compared to *doing nothing*, which of these is worth the effort?" Or "compared to the version of you in 6 months who already shipped something, which would they wish you'd picked?"

### Make the assumption explicit
Pick the one assumption everything rests on and state it plainly: "it sounds like this whole direction assumes [X]. If X weren't true, would we still be having this conversation?" Often the user hasn't noticed they're assuming X.

### Shrinking the stakes
Sometimes the lock-in is fear of the wrong choice, not conviction about the right one. Reframe: "what's the cheapest way to learn whether this is wrong before committing?" This turns a decision into an experiment and lowers the stakes enough to consider alternatives.

### Time travel
- "If you'd shipped this 3 months ago, what would you have learned by now that would change your mind?"
- "If you ship the alternative and it works, what's the first sign? If you ship your current pick and it's wrong, what's the first sign?" — the answer often reveals which choice is actually more reversible.

## When not to reframe

If the user has considered alternatives and chosen with reasons, don't keep pushing — that's conviction, not lock-in. Reframe techniques are for stuckness, not for overriding a considered decision. If unsure, ask: "are you settled on this, or still weighing?" and respect the answer.
